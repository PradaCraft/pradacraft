PRADACRAFT — WEBSITE DEMO

CARA MENJALANKAN
1. Ekstrak PradaCraft.zip.
2. Buka folder PradaCraft.
3. Buka index.html dengan Chrome atau browser lain.
4. Tekan Admin Panel untuk menambahkan addon, gambar, dan file .mcaddon/.mcpack.

FITUR DEMO
- Desain responsive untuk HP dan komputer.
- Pencarian dan kategori addon.
- Detail addon.
- Upload file addon dan gambar dari Admin Panel.
- Download file addon yang diupload.
- Penghitung download.
- Rating dan komentar.
- Addon terbaru dan terpopuler.

PENTING — BATASAN DEMO
Versi ini menyimpan konten di localStorage browser. Artinya:
- Data hanya ada pada browser/perangkat yang mengunggahnya.
- Pengunjung lain tidak otomatis melihat addon yang kamu upload.
- Jumlah download dan komentar bukan statistik global.
- File maksimal 3 MB per addon pada demo ini.
- Ini belum memiliki login admin yang aman atau server database.

AGAR MENJADI WEBSITE PUBLIK SEBENARNYA
Perlu hosting + domain + backend/database + penyimpanan file.
Backend harus memvalidasi file, membatasi upload, memindai file berbahaya,
mengamankan panel admin dengan autentikasi, dan menghitung download di server.
Jangan memakai password admin di JavaScript sisi browser.
Tambahkan kebijakan privasi, syarat penggunaan, dan pastikan punya izin
untuk membagikan addon yang diunggah. Ikuti lisensi pembuat addon.
